# Voice-play requests come from the overlay session

Who may speak is a session rule (the voice-primary pair; extra-path exceptions land later). The window used to hard-code `pairIndex != 0` next to NAudio, which hid the rule from session tests and invited a second copy of designation. The live overlay session emits voice-play requests; MainWindow only plays them. The PlayVoice toggle, file lookup, and NAudio stay in the window.
