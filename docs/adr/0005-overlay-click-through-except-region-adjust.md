# Overlay is click-through except during region adjust

The overlay sits on the game. Always-draggable subtitles steal clicks meant for in-game controls. Region adjust is armed from settings for one target at a time: a region pair (both of that pair's outlined rectangles take the mouse — grabbing a box drags that box's own rectangle, the capture or the display; arming requires either rectangle to be valid, and only valid frames are drawn and dragged), or the optional dark-screen display, or the optional dialogue-option display (display only; their bands are detected, not user rectangles). Extra-path adjust only arms when that display already exists; the first rectangle is boxed. While armed, the pair's sampling does not pause: dragging the capture means the next beat samples the new rectangle. Otherwise the overlay — subtitles, hints, and the region-pair preview — is click-through.

Amended by issue #39: adjust used to be display-only (one armed pair, only its display region draggable, arming required a valid display). The extension to capture frames, the relaxed arming rule, and the rename from display-region adjust to region adjust came out of the 2026-09-08 grilling session (issue #36).
